## Предложение на удаление

Предлагается удалить весь каталог `demo` из семи файлов, поскольку пользователь ранее определил, что работа ведётся только на базе существующей БД. Перед удалением необходимо дополнительно убрать из `index.html` поддержку параметра `?demo=1` и константу `DEMO_CONFIG_URL`.

Статус предложения: **ожидает явного подтверждения пользователя**.
